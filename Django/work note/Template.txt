**** Django Template ****
- A Django templates in a html file that can also include CSS and JAVASCRIPT.
- It is used to create a dynamic web page.
- It render data sent from inside the HTML structure.
- Help define the layout and design of each page.
- support template tag and variable name for dynamic content.
- Makes it easy to seperate presentation from application logic.

* Organizing Template 
- Django provides two way to organize template base on your project structure.
=> project level templates : a single directory shared acroll all apps.
=> App level templates: seperate template directories for individual app, useful in large project or when ddifferent layout needed.

* Template Setup in Django
- A single etemplate directory at the project level can be for simplicity, storing all template in a one centeral location.
- Configuration in setting.py
- ex:   TEMPLATES = [
            {
                'DIRS': [BASE_DIR / 'templates'],
            }
        ]

**** Variable in Django Templates ****
- Django template allow HTMLto be dynamically generated by dynamic content with data process from view.
- Variable are used to display this dynamic data within templates.
- Key characteristics of Django template variable are:
- Variable come from the context dictionary provide by the view.
- they render value directly into HTML.
- can dynamic context such as string, number, list and object
- Enable seperation of presentation from bussiness logic.

=> full example
    - (i) views.py  
        from django.shortcuts import render
        def index(request):
            context = {
                "firstname": "jay",
                "lastname": "desai",
                'age': 21
            }
            return render(request, "index.html",context)

    - (ii) index.html 
        {{firstname}}
        {{lastname}}
        {{age}}



**** Template Tags ****
- Django Template entire provide tag that and logic and control flow to templates. 
- Tag allow execution of operation such as condition check, loop, including external file, and external base templates.
- Few thing about template tag are that it:
- Enable adding logic direct in templates.
- Enclosed within {%  %} delimiters.
- Can output content, control rendering, or include external resource.
- often used alongside template variable ({{ }}) for dynamic rendering.

- Syntax
    {% tag_name [argument] %}

- Example
    {% csrf_token %}

* Commonly Used Django Template Tag

=> (i) comment
    - Comment Ignore everything between {% comment %} and {% endcomment %}
    - optionally add a note for documentation perpose.
    - ex:   {% comment %}
                This is comment part
            {% endcomment %}

=> (ii) Cycle
    - Cycle through a list of value with each loop iteration.
    - Useful for alternating row classes.
    - ex:   {% for i in list %}
                <p>{{i}}</p>
            {% endfor %}

=> (iii) Extends 
    - Extends are used for template Inheritance allow a template to Inherit from a base template.

    - This ensure cleaner template, easire maintenance, and consistent layout throughout the site.
    -   dir1/
            template.html
            base2.html
            my/
                base3.html
        base1.html

    -   {% extends "./base2.html" %}
        {% extends "../base1.html" %}
        {% extends "./my/base3.html" %}
    
    - Full Example

                <head></head>

                    {% include "header.html" %}

                    {% block content %}

=> (iv) if, elif, else
    - The "if" tag in Django Template control what content is display base on condition.
    - It can be combine with "elif" and "else" to handle multiple condition scenarious, allowing template to show a different content depending on various condition.
    - This provide a flexible way to dynamically render HTML base on data passed from view.
    - ex:   {% if age %}
                value in data is {{age}}
            {% else %}
                Data empty
            {% endif %}

=> (v) for loop
    - Django template allow rendering dynamic data by embedding python like logic into HTML.
    - The for loop used iterate over list or other iterable objects.
    - This enable displaying reapeated content, such as list or table, directly in templates, without adding complex logic in the view.
        - ex:   {% for i in list %}
                    <p>{{i}}</p>
                {% endfor %}

    - for with empty display an alternative messsage if the list is empty
    - ex:   {% for i in list %}
                <p>{{i}}</p>
            {% empty %}

=> (vii) Boolean Operators with if
    - if tag evalute a variable, and if that variable is "true"(i.e. exits, is not empty, and is not "false" Boolean value) the content of the block are output.
    - one can various boolean operator with if template tag.
    - ex:   {% if age >= 18 %}
                you are aligable are for a vote

=> (viii) firstof
    - The {% firstof %} tag in django template display the first variable or value that evalute to true from a list of arguments.
    - It si used when multiple variable may contain data and a fallback value need to true need to be display if earlier variable are empty, undifine to false.
    - ex:   {% firstof gender lastname firstname age city %}  # fistvalue print not none not empty

=> (ix) include
    - include load and render another template within the current template.
    - ex:   {% include "header.html" %}

=> (x) lorem
    - lorem generate random "lorem ipsum" text, useful for a place hlder text.
    - ex:   {% lorem %}     # Outputs one paragraph #

=> (xi) now 
    - now display the current date/time using the sepcified fromat.

=> (xii) url
    - url return absolute path reference matching a given view and operational parameter.
    - this is way to output violating the DRY priciple by having hard code URLs in your template.

**** Fiter in Template ****
- Django template engine provide filter to transform the value of variable and tag argument.
- Unlike template tag which control logic or structure, filter are specifically used to modify or format variable value.
- Syntax:   {{ variable_name | filter_name }}
- Filter can be "chained" meaning the output of one filter can be applied to the next {{ text | escape | linebreak }} is a common idiom for escaping text contents,
  then converting line break to <p> tags.

=> (1) add
    - It is used to add an argument to the value.
    - ex: {{ a | add:"5" }}

=> (2) capfirst
    - It is used to capitalize the first character of the value.
    - ex:   {{fname | capfirst}}

=> (3) date 
    - It is used to format a date according to given formate
    - ex:   {{ dt | date:"D d M Y" }}

=> (4) default
    - It is used to give a default value to a variable evalutes of False, it will use the default argument given else the variable value itself.
    - ex:   {{ city | default:"nothing"}}

=> (5) escape
    - the escape filter convert special HTML character into safe representation to present rendering as HTML.
    - ex:   {{ description | escape }}

=> (6) length
    - It is used to return the length of the value. This work with both list and string.
    - ex:   {{ fname | length }}

=> (7) lower
    - It is used to converts a string into all lowercase.
    - ex:   lower : {{ lname | lower }}

=> (8) upper
    - It is used to convert a string into all uppercase.
    - ex:   upper : {{ lname | upper }}

=> (9) title
    - It is used to convert string titlecase by making word start with an upper case character and the remainin character lowercase.
    - ex:   title : {{ description | title }}

=> (10) join
    - It is used to join a list with a string, like a python str.join(list)
    - ex:   join : {{ l1 | join:" // " }}

=> (11) addslashes
    - It is used to add slashes before quote.
    - useful for escaping string in CSV.

=> (12) center 
    - It is used to center the value in a field of given width.
    - ex:   center: "{{description | center:"50"}}"

=> (13) cut 
    - It is used to remove all value of arg from the given string.
    - ex:   cut : {{ string | cut:" "}}

=> (14) dictsort
    - It take a list of dictionary and return an list store by the key given in the argument.
    - ex:   name dictsort : {{ dictionary | dictsort:"name"}}

=> (15) divisibleby
    - It return True If the value divided by the argument.
    - ex:   divisibleby : {{ a | divisibleby:"3"}}

=> (16) filesizeformat
    - It is used to format the value like a 'human readable' file size(e.g., 13KB, 3MB)
    - ex:   filesizeformat {{ a | filesizeformat }}

=> (17) first
    - It is used to first item in a list
    - ex:   first : {{ l1 | first}}

=> (18) last
    - It is return to last item in a list.
    - ex:   last : {{ l1 | last }}

=> (19) linenumbers
    - It is used to display text with line number
    - ex:   linenumbers : {{ linenum | linenumbers }}

=> (20) make_list
    - It is used to return value turned into a list.
    - For string is a list character.
    - For a integer, the argument is cast to a string before creating list.
    - ex:   make_list : {{ make_list | make_list }}



**** Template Django ****
- Django extends tag enable reusing base template across multiple page, elimiting the need duplicate html code.
- This ensure cleaner template, easire maintenance, and a consistent layout through the site.

=> Full Example:
    - (i) index.html
        {% extends "base.html" %}
        {% block content %}
            <p> This is paragraph </p>
        {% endblock %}

    - (ii) base.html
        <html>
            <head></head>
            <body>
                {% include "header.html" %}

                {% block content %}
                    
                {% endblock %}

                {% include "footer.html" %}
            </body>
        </html>
    
    - (iii) urls.py
        from django.urls import path
        from temp_app import views

        urlpatterns = [
            path('', views.index, name='index'),
        ]

    - (iv) views.py
        def index(request):
            return render(request, "index.html")

- The {% extends %} tag tell django that the current template should Inherit the layout and structureof base.html
- The child template can then override specific {% block %} section define in parent template.



**** Boolean Operator ****
- Django template support boolean operator to combine or negate condition in if statement.
- These operator allow more complex condition logic directly in templates.
- and : Check all condition are true.
- or : check if at latest one condition is true.
- not : Nagate the condition.

* Common Boolean Operator 
=> views.py
    def boolean_operator(request):
        l1 = ["apple", "banana", "mango", "kiwi"]
        context = {
            "x" : 20,
            "y" : 30,
            "l1" :l1
        }
        return render(request, "boolean_operator.html", context)
=> (1) == (Equal to)
    - return a true the value on both side of the operator are equal.
    - ex:   {% if x == y %}
                x is equal to y
            {% elif x != y %}
                x is not equal to y
            {% endif %}

=> (2)  != (Not equal to)
    - return True are value is not equal.
    - ex:   {% if x == y %}
                x is equal to y
            {% elif x != y %}
                x is not equal to y
            {% endif %}

=> (iii) < (Less than)
    - Check if the left value is less than the right value.
            {% if x < y %}
                x Less than y
            {% endif %} 

=> (iv) > (Grater than)
    - Check if the left value is Grater than the right value.
    - ex:   {% if x > y %}
                x Greater than y
            {% endif %}

=> (v) <= (Less than or Equal to)
    - check if left value is less than or equal to the right value.
    - ex:   {% if x <= y %}
                x Less than or Equal to y
            {% endif %}

=> (vi) >= (Greater than oe Equal to)
    - check if left value is Grater than or equal to the right value.
    - ex:   {% if x >= y %}
                x Greater than or Equal to y
            {% endif %}

=> (vii) in operator
    - Test if a value exists in list, string, or Queryset.
    - ex:   {% if "apple" in l1 %}
                True
            {% endif %}

=> (viii) not in operator
    - It is the opposite of the in operator.
    - ex:   {% if "watermalon" not in l1 %}
                True
            {% endif %}
