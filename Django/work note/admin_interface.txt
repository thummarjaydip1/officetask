**** Create Super User ****
- Django comes with a built-in admin panel that help developer manage the database, user and application model efficiently, without needing seperate interface.
- To aacess in the use the admin panel, a super user must be created.
- A superuser is a user with full administrative privilegas.
- The admin panel allow you to add, edit, and delete model data.
 
* Step to create a Superuser.
- Before creating a superuser, ensure your project has been migrated to set up neccesarry database table. 

=> (i) Navigate to the project directory
    - Open terminal or command prompt and move to hte directory where your manage.py file location.
    - cd/path/your/django/project

=> (ii) Run on super creation command
    - Execute the following command t initiate the superuser creation process.
    - python manage.py createsuperuser

=> (iii) Enter require detail
    - username : choose a username for the superuser.
    - email : provide an email address(optional, can be left blank).
    - password : Enter secure password and confirm it when prompted.

=> (iv) successful superuser creation
    - it all field are enterd correctly, superuser created successfully.


* Login into Django admin panel
=> (i) Start the Django development server.
    - python manage.py runserver.

=> (ii) open web browser navigate to the django admin login page:
    - http://127.0.0.1:8000/admin

=> (iii) Enter the username password you set while creating the super user.


* Additional superuser operation 

=> (i) changing superuser password
    - If the superuser password is forgotted, reset it using.
    - python manage.py changepassword username.

=> (ii) create multiple superusers.
    - Additional superuser can be created by running the create super user command again.

=> (iii) Managing User via shell 
    - superuser can also be created or managed from the shell.
    - python manage.py shell
    - from django.contrib.auth.model import User.
    - User.objects.create_superuser('newadmin','admin@gmail.com', 'securepassword')


**** Django Admin Interface ****
- The admin interface is a built-in feature that provide a web base dashboard to manage project data through models.
- It enable developer and administrator to handle data efficiently without writing SQL or extra backend code.
- provide a ready to use browser based management interface.
- allow adding, editing, and deleting record across register model.
- suppport managing user, groups and permission from a single place.
- can be customized and extended according to project requirement.

* Accessing Admin panel 
- To access the admin interface:

=> (i) Start developer server.
    - python manage.py runserver.

=> (ii) Open the admin URL
    - http://127.0.0.1:8000/admin

=> (iii) Login using valid admin credentails.
    - There are basically two ways to access the django admin panel
    => Superuser : Has full access to all model and setting.
    => Staff user with permission :  Has limited access based on assigned permission. can be marked as staff(is_staff=True) and given model - level permission 
                                     through the admin interface or Django shell.
    
* Accessing With Superuser
- The admin app (django.contrib.admin) is enable by default and already added to the INSTALLED_APP list present in the setting.py 
- run the createsuperuser command 
- provide require information like username, email, password. 
- the start django server and go to http://127.0.0.1:8000/admin login super credentails and you see django admin dashboard.

**** CRUD Operation in Django Admin ****
- Django admin is a built in tool that automatically generate a web interface for the model, removing the need to create seperate page or form.
- It provide an intitive way to manage project data and perform CRUD Operation efficiently.

* Creating the App and Model
- consider project name 'admin_pro' having an app 'admin_app'.
- after creating the app, make sure to add your app to the INSTALLED_APP list in settings.py file of the 'admin_pro'.

=> (i) Define the Model in models.py
    - In admin_app/models.py create Book model to represent book in your library.
    - ex:   from django.db import models
     
            class Book(models.Model):
                title = models.CharField(max_length=200)
                author = models.CharField(max_length=100)
                publish_date = models.DateField()
                page = models.IntegerField()
                available = models.BooleanField(default=True)

                def __str__(self):
                    return f"{self.title} by {self.author}"

=> (ii) Migration your Database 
    - After creating this model, we need to run two command in order to create database for the same.
    - python manage.py makemigrations
    - python manage.py migrate

=> (iii) Register the model in Django admin
    - To manage Book record via the admin panel, register model in admin_app/admin.py
    - ex:   from django.contrib import admin
            from .models import 
            @admin.register(Book)
            class BookAdmin(admin.ModelAdmin):
                list_display = ('title', 'author', 'publish_date', 'page', 'available')
                search_fields = ('title', 'author')
                list_filter = ('available', 'publish_date')

=> (iv) Create a superuser to access admin panel
    - python manage.py createsuperuser
    - provide username, email, password. 
    - The superuser account has full access to admin panel.

=> (v) Configure admin urls
    - open admin_pro/urls.py and ensure the admin / path is included in the urlpattern list.
    - ex:   from django.contrib import admin
            from django.urls import path, include

            urlpatterns = [
                path('admin/', admin.site.urls),
                path('', include('admin_app.urls'))
            ]

=> (vi) Run the developer server 
    - python manage.py runserver    
    - and visit http://127.0.0.1:8000/admin and log in with your superuser credentails to access the admin panel.

=> (vii) Performing the CRUD operation 
    - (1) Create a New book Record
        - click books in the admin sidebar.
        - click add book.
        - fill the detail like title, author,...
        - click save to add book.

    - (2) Read Book 
        - The book list page show all saved book.
        - Use the search bar or filter on the right to find specific book quickly.

    - (3) Edit and existing book
        - click on book title from the list.
        - Update any detail in the form.
        - click save to apply change.

    - (4) Delete Book 
        - select the book/books.
        - select the DELETE option from the dropdown above the list of books.
        - confirm to permanently remove from the book.


**** Customize Django Object Name with __str__ method ****
- when django model instance are created, they appear in the admin interface with generic lable like ModelName object(1).
- This default naming can make it difficult to identify specific record when multiple entire exist.
- Django uses a generic place holder when no readable name is Define.
- Meaningful names help quickly identify record in the admin panel.
- overriding the __str__() method in the model class define how object are displayed.
- Improves clarity and usability for developers are administrator.
- To make objects more readable in the admin, add __str__method to the model. This method should return a desriptive string representing the object.
- ex:   class Student(models.Model):
            name = models.CharField()
            age = models.IntegerField
            addres = models.TextField()

            def __str__(self):
                return self.name



**** Django Admin Redesign and Customization ****
- The default admin interface is often sufficient for most projects, but sometimes more control and Customization are needed.
- Django provide powerful tool to tailor the admin panel to specific requirement.

* Customization
- (i) changing order or fields.
    - By default, fields in the admin detail view appear in the same order as define in the model.
    - This order can be changed directly in admin.py without modifying admin.py 
    - ex:   from django.contrib import admin
            from .models import Student

            class StudentAdmin(admin.ModelAdmin):
                fields = ['name', 'age', 'address']

            admin.site.register(Student, StudentAdmin)


- (ii) Adding search and filters
    - currently, the model contain only a few entire.
    - As the number of entire grows to hunderends or thousands, finding specific data by browsing manually becomes tedious. 
    - Addinf search filter and filter featurein the admin panel make it easire to access specific entire quickly.
    - ex:   search field
            search_fields = ('title', 'author')

    - ex:   filter field
            list_filter = ('available', 'publish_date')


- (iii) Viewing Additional fields
    - In the admin interface, the list view normally shows only one fields per model.
    - Using list_display, Additional fields can be added to make the list view more information.
    - ex:   from django.contrib import admin
            from .models import Student

            @admin.register(Student)
            class StudntAdmin(admin.ModelAdmin):
                list_display = ["id", "name", "age", "addres"]

- (iv) Edit View list 
    - field can be made editable directly from the list view using list_editable, eliminating the need to open each detail view.
    - ex:   from django.contrib import admin
            from .models import Student
            @admin.register(Book)
            class BookAdmin(admin.ModelAdmin):
                list_display = ('title', 'author', 'publish_date', 'page', 'available')
                search_fields = ('title', 'author')
                list_filter = ('available', 'publish_date')
                list_editable = ["page"]

- (v) Admin Template
    - To modify the layout or appearence of the Django admin interface, such as changing header, custom template can be added to the project.
    - This involve creating a specific folder structure and Adding custom HTML file to override default admin template.
    - Steps.
        - create a template folder in the project root.
        - inside the template, create a folder name admin.
        - add file name base_site.html inside template/admin/ to customize the admin interface branding.
        - ex:   - admin_app/
                    - template/
                        - admin/
                            - base_site.html
