**** Django Forms ****
- Django Forms are used to collect input from users, check if the input is correct and process the data.
- Gather information throught from fields such as text, email or password.
- can save the clean data to the database when needed.
- provide a clean way to handle user input in web application.
- syntax:
    field_name = forms.FieldType(**options)
    - field_name : Name of the form fields
    - FieldType : Type of the fields(like a CharField, IntegerField, EmailField).

* Create a Simple Django Form
- Before Creating form, ensure that a Django project(forms_pro) and app(forms_app) are already setup.
- Creating a form in Django is similar to Creating a model, as it require specific field and their type.
- To Create a form, Create a "forms.py" in the app folder.
- ex:   from django import forms 

class StudentForm(forms.Form):
    name = forms.CharField()
    age = forms.IntegerField()
    email = forms.EmailField()

**** Rendering Django Form Field ****

- Rendering Django form field manually allow a full control over how each input element looks and behave in the HTML.
- Each field is written separatly in the template, giving complate control over layout and string.
- Django provide a built in method to render from field automatically when customization is not require.
- Manually redering useful when applying custom CSS, special UI design, or specific HTML structure.
- offer flexibility for Creating from that match a project design need.

* built - in Method to display form
- A form provide three built in method to render field.
- {{ form.as_p }} will render them wrapped in <p> tag.
- {{ form.as_table }} will render them as table cell wrapped in <tr> tag.
- {{ form.as_ul }} will render them wrapped in <p> tag.

=> Full Example
    - (i) models.py
        from django.db import models
        class Student(models.Model):

        from django import forms

**** Form Validation ****
- Form Validation ensure that user submit data meet specific requirement before begining process or saved.
- It can be applied to such as username, gender, or text input to maintain accuracy and consistency.
- Django simplifies the process by combinig from handling and validation logic within its from classes.

=> Example : Custom validation with django Forms.
    - (i) Create Model
        from django.db import models
        class FeedBack(models.Model):
            name = models.CharField()
            age = models.IntegerField()
            message = models.TextField()

    - (ii) Apply migrations
        - After creating tthis model, two command need to be run and to create the corresponding database table.
        -   python manage.py makemigrations
        -   python manage.py migrate
    
    - (iii) Create ModelForm With Validation
        from django import forms
        from .models import FeedBack

        class FeedbackForm(forms.ModelForm):
        class Meta:
            model = FeedBack
            fields = ["name", "age", "message"]

        def clean(self):
            cleaned_data = super().clean()

            name = cleaned_data.get("name")
            message = cleaned_data.get("message")

            if name and len(name) <= 3:
                self.add_error('name', 'minimum 3 character apply')
            if message and len(message) <= 10:
                self.add_error('message', 'minimum 10 character required')

            return cleaned_data

    (iv) Define a View
        from django.shortcuts import render
        from django.http import HttpResponse
        from .forms import StudentForm, FeedbackForm
        def feedback_form(request):
            form = FeedbackForm()
            if request.method == "POST":
                form = FeedbackForm(request.POST)
                if form.is_valid():
                    form.save()
                    return HttpResponse("Data Send Successfully")
            return render(request, "feedback.html", {"form":form})

    (v) configure URLs
        from django.urls import path
        from forms_app import views

        urlpatterns = [
            path("feedback/", views.feedback_form),
        ]

    (vi) Create template
        <form method="POST">
            {% csrf_token %}
            {{form.as_p}}
            <button type="sumbit">Send</button>
        </form>

    (vii) Runserver
        - python manage.py runserver 
        - visit site http://127.0.0.1:8000/feedback


**** Django ModelForm ****
- A ModelForm is a class that automatically generate a from a Django model.
- It link your form field directly to the model field, reducing repetitive code and making from creation faster and cleaner.
- ModelForm also provides built-in method with validation to simplify from processing.

=> Example: ModelForm full example.
    
    - (i) Create the model
        class Contact(models.Model):
            name = models.CharField()
            age = models.IntegerField()
            email = models.EmailField()
            address = models.TextField()
            
    - (ii) Register Your App 
        INSTALLED_APPS = [
            # other apps,
            'forms_app',
        ]
    
    - (iii) Make migrations and migrate
        - Run following command
        - python manage.py makemigrations
        - python manage.py migrate
    
    - (iv) verify model creation
        - verify that the model interface is accisible in the django admin interface by visiting.
        - http://127.0.0.1:8000/admin/forms_app/contact/add/

    - (v) Create the ModelForm
        from django import forms
        from .models import *
        
        class ContactForm(forms.ModelForm):
            class Meta:
                model = Contact
                fields = "__all__"

        - Field : A list of special value '__all__' indicating which model fields should be included in the form. 
                  It is highly recommanded to explicitly specify the field to avoid potential decurity risk.
        - exclude : A list of find to exclude from the form.(for in not display) ex: exlude = ["image"]

    - (vi) User the model form in the views
        def contact_form(request):
            form = ContactForm()
            if request.method == "POST":
                form = ContactForm(request.POST)
                if form.is_valid():
                    form.save()
                    return HttpResponse("Date Send Successfully")
            return render(request, "contact.html", {"form":form})

* customizing field widgets

                }
        
**** Django formset ****
- Django formset allow managing multiple instance of the same from a single page. 
- instance of creating each from django Formset simplify managing a multiple instance of the same for on a single page.
- Instead creating each from seperately, formset group them together, allowing all forms to be displayed, validated and process simulataneously.
- For instance, when user need to add multiple article at once, a formset can render several article forms together, making it easire to handle multiple input efficiently.

=> Full Example Viewset
    - (i) Create Model
        class Person(models.Model):
            name = models.CharField()
            age = models.IntegerField()
            city = models.CharField()

    - (ii) Define Basic form
        class PersonForm(forms.Form):
            name = forms.CharField()
            age = forms.IntegerField()
            city = forms.CharField()

    - (iii) Create formset in views
        - In viwes.py import fromset_factory and create a view to render the formset.
        def person_form(request):
            PersonFormSet = formset_factory(PersonForm)
            form = PersonFormSet()
            return render(request, "person.html", {"form": form})
    
    - (iv) Render formset in template
        <h2> Person Form</h2>
        <form method="POST">
            {% csrf_token %}
            {{form.as_p}}
            <button type="sumbit">Send</button>
        </form>

    - (v) Handling multiple form in extra
        - By default, a formset display a one form. To show multiple form, use the extra parameter.
        def person_form(request):
            PersonFormSet = formset_factory(PersonForm, extra=3)
            form = PersonFormSet()
            return render(request, "person.html", {"form": form})



**** Django ModelFormSet ****
- Django ModelFormSet allow managing multiple model based on a single page.
- They enable creating, updating or deleting multiple instance of a model at once, using group of form tied to the model's fields.
- Each from in the formset correspods to a single model instance.

* Using ModelFormSet Example
- (i) models.py    
    class Book(models.Model):
        title = models.CharField()
        page = models.IntegerField()
        description = models.TextField()


- (ii) forms.py
    from django.forms import modelformset_factory
    from .models import Book 
    BookForm = modelformset_factory(Book, fields=["title", "page", "description"])

- (iii) views.py
    from django.http import HttpResponse
    from django.forms import formset_factory, modelformset_factory
    from .models import Book

- (iv) templates/book.html
    <h2> Book Form</h2>
    <form method="POST">
        {% csrf_token %}
        {{form.as_p}}
        <button type="sumbit">Save</button>
    </form>
